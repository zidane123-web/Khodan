Je veux que tu rédiges un plan chronologique complet pour finaliser entièrement une application (interface, logique, backend, fonctionnalités, tests, déploiement, etc.).

Le but est de créer une arborescence claire de fichiers représentant chaque tâche individuelle à accomplir pour que l’application soit terminée à 100 %.

🔹 Structure attendue :

Crée un dossier racine /plan.

Chaque tâche est un fichier individuel à l’intérieur de ce dossier.

Le nom de chaque fichier doit suivre la logique suivante :

/plan/001_DesignPageAccueil.md  
/plan/002_AjouterNavigation.md  
/plan/003_ConfigBaseDeDonnees.md  
/plan/004_AjouterLoginFirebase.md  
...


La numérotation (001, 002, 003…) indique l’ordre chronologique exact d’exécution.

Le nom du fichier résume clairement l’action à accomplir.

🔹 Contenu de chaque fichier de tâche :

Titre de la tâche

Objectif / But de la tâche

Étapes concrètes à suivre (détaillées une à une)

Fichiers ou modules concernés (ex: main.dart, sales_screen.dart, api_service.dart...)

Résultat attendu / Critère de réussite

Prérequis éventuels (autres tâches ou dépendances)

🔹 Organisation globale :

Les tâches doivent couvrir tout le cycle de production :

Interface / UI Design (création des pages, thèmes, composants).

Logique & Navigation (flux, états, gestion des données locales).

Backend / API / Base de données (connexion, modèles, sécurité).

Fonctionnalités métiers (ventes, achats, paiements, notifications, etc.).

Tests, optimisation et déploiement (Firebase Hosting, Play Store, etc.).

🔹 Format attendu en sortie :

Une liste complète de tous les fichiers-tâches, avec :

leur nom exact,

un résumé d’une ligne,

puis le contenu complet du fichier.

Aucune tâche ne doit être oubliée : le plan doit être exhaustif, logique, et actionnable immédiatement.

✳️ Agis comme si c’était ton propre projet, que tu devais finaliser toi-même sans rien laisser.
✳️ Fournis tous les fichiers de tâches, bien numérotés, prêts à être exécutés un par un.
