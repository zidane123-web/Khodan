# Tâche 01 - Cartographier Khodan par rapport à Everbreed

## Objectif
Comprendre précisément l’écart entre l’application Khodan actuelle et l’expérience Everbreed afin de guider toutes les étapes suivantes sans écrire de code pour le moment.

## Sous-tâches
1. Relire les deux rapports fournis (résumé Everbreed + plan détaillé) et noter toutes les sections (menus, écrans, formulaires, rapports, automatisations, abonnements).
2. Dresser dans un fichier Markdown `docs/everbreed-gap-analysis.md` un tableau à trois colonnes : « Module Everbreed », « Ce qui existe déjà dans Khodan », « Travail à prévoir ». Utiliser des phrases simples, indiquer « inconnu » lorsque l’information manque.
3. Ajouter au même document une liste des éléments techniques sensibles (ex. accès Supabase difficile, modules inexistants, traductions manquantes).
4. Demander, si besoin, des informations complémentaires (captures d’écran, textes) avant d’avancer : lister ces questions à la fin du document.

## Livrables
- Fichier `docs/everbreed-gap-analysis.md` contenant le tableau et les questions ouvertes.

## Notes
- Aucun code ni migration à produire ici : l’objectif est uniquement de clarifier la vision.
- Utiliser un français simple (phrases courtes, vocabulaire non technique).
- Ce document servira de référence pour toutes les autres tâches ; prendre le temps nécessaire pour bien le compléter.
