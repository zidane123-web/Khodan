# Tâche 02 - Concevoir le plan de projet Khodan

## Objectif
Transformer la cartographie en plan d’action clair (fonctionnalités, ordre de réalisation, dépendances) accessible à un débutant.

## Sous-tâches
1. S’appuyer sur `docs/everbreed-gap-analysis.md` pour lister tous les modules à créer ou améliorer (navigation, éleveurs, portées, planning, santé, finances, rapports, etc.).
2. Créer un fichier `Plan2/roadmap-khodan.md` décrivant :
   - Les phases (Phase 1 : base, Phase 2 : modules avancés, Phase 3 : personnalisation et abonnements).
   - Pour chaque phase, les modules à livrer, les dépendances, les prérequis techniques.
3. Indiquer pour chaque module les impacts principaux (Flutter, Supabase, tests) pour anticiper la charge.
4. Ajouter une section « Risques et astuces » (ex. si Supabase CLI échoue, utiliser SQL Editor).

## Livrables
- Fichier `Plan2/roadmap-khodan.md` clair et structuré.

## Notes
- Ne pas coder : il s’agit d’un document de planification stratégique.
- Utiliser des phrases indicatives (« Faire ceci… ») et éviter le jargon.
