# Tâche 07 - Gérer portées, kits et clapiers

## Objectif
Recréer un module complet pour les portées et les cages (création, édition groupée, affectation des kits, suivis de poids).

## Sous-tâches
1. Créer `docs/litters-spec.md` décrivant les formulaires : création de portée, édition, affectation de cage/enclos, suivi des poids et abattage groupé.
2. Implémenter la création de portée (formulaire avec validation, rattachement à un modèle de tâches).
3. Mettre en place l’édition groupée (sélection multiple + formulaire simplifié).
4. Ajouter l’écran « Clapiers » : lister les cages/enclos, afficher les kits, permettre l’enregistrement des poids pré/post abattage et la valeur marchande.
5. Tester chaque écran (listes, formulaires) et vérifier l’absence d’avertissements.

## Livrables
- `docs/litters-spec.md`.
- Code Flutter pour les écrans Portées et Clapiers avec tests widgets de base.

## Notes
- Utiliser des intitulés clairs (« Numéro de clapier », « Poids carcasse (kg) »).
- Mentionner dans la documentation comment saisir les valeurs si l’utilisateur travaille hors-ligne.
