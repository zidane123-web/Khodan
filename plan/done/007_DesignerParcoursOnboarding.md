# Designer le parcours onboarding

## Objectif / But
Definir l experience utilisateur complete pour la decouverte, l activation et la configuration initiale de l application.

## Etapes concretes
- Identifier les personas et objectifs des nouveaux utilisateurs (type d elevage, taille de troupeau, localisation).
- Tracer le flux des ecrans onboarding (intro, tutos, creation de ferme, import de donnees).
- Produire les maquettes haute fidelite pour chaque ecran avec variantes mobile et desktop.
- Valider l accessibilite (contrastes, tailles, textes) et la localisation potentielle.
- Integrer les maquettes et annotations dans l outil de design partage pour les devs.
